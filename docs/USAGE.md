# 使用指南

## 第一次開啟

滑鼠靠近螢幕頂部的小島會展開功能面板。左右箭頭和底部圓點切換頁面；在列表內部滾輪檢視更多內容。系統匣選單可開啟設定、控制開機啟動或退出程式。

設定裡的功能顯示開關可以隱藏不常用的頁面；隱藏頁面不等於刪除它的資料。

## 信箱

在「設定 → 郵件」新增完整信箱地址，選擇服務商並填寫授權碼或 App 專用密碼。不要把密碼傳送到聊天、Issue 或截圖裡。

| 信箱 | 取得連線憑據 |
| --- | --- |
| QQ | QQ 信箱網頁版右上角「設定」→「帳號與安全」→「安全設定」→「POP3/IMAP/SMTP/Exchange/CardDAV 服務」→開啟服務並產生授權碼 |
| 163／126 | 信箱網頁版「設定」→「POP3/SMTP/IMAP」→開啟 IMAP，並按頁面驗證產生用戶端授權密碼 |
| 騰訊企業郵 | 網頁版設定中的用戶端收發設定；企業管理員可能限制 IMAP 或第三方用戶端 |
| iCloud | Apple 帳號開啟雙重認證後，在帳號安全頁面產生 App 專用密碼 |
| Gmail | Google 帳號開啟兩步驟驗證後產生應用專用密碼；組織帳號可能由管理員停用此入口 |

以服務商目前頁面為準，島仔設定頁也提供對應說明和網頁入口。Gmail 在部分網路環境下需要能連上 Google；島仔不會替你改變系統網路設定。

Outlook、Hotmail、Live 和 Microsoft 365 雲信箱需要 OAuth 授權，目前暫不支援。設定頁明確標註支援狀態；填寫微軟個人信箱地址或已知的微軟雲 IMAP 主機時，會提示並停用測試及儲存按鈕。

連線後讀取最近 20 封郵件；執行期間列表最多保留 60 封。新郵件優先透過 IMAP IDLE 接收，並有定期防漏檢查；伺服器、網路及服務商投遞耗時仍會影響實際到達時間。

驗證碼卡片顯示來源與主題，點選即可複製。點郵件列表進入詳情，滾輪檢視內文；「閱讀全文」開啟獨立閱讀視窗。內文中的網頁連結交給預設瀏覽器開啟。

HTML 郵件保留標題、列表、粗體、引用和表格的閱讀結構。圖片顯示有意義的替代文字，不自動載入遠端圖片；內文支援選擇複製。

郵件列表可切換「全部／未讀」。開啟郵件後會標為已讀，也可在郵件行、詳情或全文視窗手動切換已讀狀態。刪除會移到目前模式的回收站；點選列表右下角的垃圾桶圖示進入回收站，可將郵件還原到收件匣。「設定 → 郵件 → 同步郵件操作到信箱」預設關閉，僅在本機儲存整理狀態，不改動真實信箱；開啟後已讀、刪除和還原會同步到伺服器，失敗時保留列表記錄並提示。遠端刪除和還原要求信箱支援 IMAP MOVE。僅提供 UIDPLUS 的信箱可使用本機回收站。切換開關不會補交之前的本機操作。

列表和篩選數量對應目前載入的最近郵件；僅本機模式下「全部已讀」只處理目前載入的記錄；開啟同步後會處理已連線信箱的全部未讀郵件，不限於列表記錄。一般狀態重新整理只讀取最近郵件標記，內文優先重複使用記憶體快取。

## 日程

在「設定 → 日程」選擇平臺，填寫平臺提供的 CalDAV 連線資訊。只登入或安裝飛書、釘釘、企業微信桌面用戶端，不會自動授予島仔日曆讀取權限。

- 左側月曆選擇日期；右側按時間顯示日程，全天安排在前。
- 大卡片顯示選中的日程；滾輪只滾動下方列表，點選其他條目切換大卡片。
- 跨天日程會出現在覆蓋的日期中。結束時刻按日曆提供的資料展示。
- 自動同步預設每 5 分鐘進行；點選右上角更新時間可手動重新整理月份。
- 提前提醒時間可在設定中選擇 5／15／30 分鐘；全天安排展示在日曆中，不在午夜彈出會議提醒。
- 一般郵件內文中的日期不會加入日程；帶日曆附件的正式邀請會自動顯示。
- 郵件日程右側的 × 可忽略該日程，停止顯示與提醒；在郵件詳情或全文視窗選擇「恢復日程」可恢復。忽略郵件來源不會刪除工作日曆中的對應安排。

**目前限制：** 郵件日程依賴目前載入的郵件記錄，不是完整信箱歸檔；複雜的批次重複規則修改可能提示不支援。日曆同步失敗會顯示錯誤，不能把「已連線」當成所有日程都已成功同步。程式退出、電腦關機或睡眠期間無法持續接收提醒。

## 音樂、專注、飲水與待辦

音樂來自 Windows 媒體工作階段，播放器需要提供系統媒體資訊。歌詞比對依賴歌曲中繼資料和外部服務，個別版本、純音樂或未找到歌詞的歌曲可能無法顯示同步歌詞。

專注與休息需點選開始，結束後可進入下一階段。飲水可設定目標、單次量、提醒間隔和時段；記錄錯誤可以復原。待辦提醒是可選項，填寫任務後透過日期／時間選擇器設定，不需要手寫時間格式。

## AI 額度

先登入相應工具，再在島仔 AI 額度設定中識別本機帳號。多個帳號可分別命名、選擇配色並決定是否常駐。Codex、Claude、Kimi 的登入由各自用戶端管理。Claude 桌面版僅讀取本機歷史和用量快取，切換帳號後需等待新記錄。手動啟用 Claude Code 本地採集時，島仔會寫入採集指令碼並設定狀態列，已有其他狀態列命令時保留原設定。

Grok Bot、Gemini、豆包提供各自的連線入口；工作階段過期時重新連線。豆包讀取網頁會員的 5 小時、每週及活動額度：點選「瀏覽器登入」，優先使用系統預設的 Chrome／Edge，在獨立視窗完成官網登入，無需瀏覽器擴充功能；預設瀏覽器不支援時使用已安裝的 Chrome／Edge。也可點選「從本機匯入」讀取豆包用戶端目前帳號，或手動提供 Cookie。本機登入快取被用戶端佔用時，請使用瀏覽器登入。登入狀態加密儲存在本機。額度介面、訂閱類型和服務商策略可能變化，未識別或請求失敗時應以對應服務的官方頁面為準。

## 更新、解除安裝與資料目錄

雙擊新版 `Daozai-Setup-v版本號-x64.exe`，可透過路徑輸入框或瀏覽按鈕選擇安裝資料夾，勾選建立桌面捷徑與開機自動啟動，再按安裝按鈕。首次安裝預設建立桌面捷徑、不開機自動啟動；升級預設保留現有選擇。安裝位置預設為 `%LOCALAPPDATA%\Programs\Daozai`，可改為其他有寫入權限的資料夾，使用者資料仍儲存在 `%APPDATA%\Daozai`。

升級安裝保留資料。若提示島仔正在執行，先從系統匣退出，再點選重試。

在 Windows「已安裝的應用程式」中解除安裝會移除程式和捷徑，但保留資料。若要清除帳號，先在島仔設定中移除對應連線，避免只刪設定檔而留下系統憑據。

## 常見問題

**視窗沒有出現：** 檢查系統匣是否已有執行中的實例、是否在全螢幕應用中、設定是否啟用了全螢幕隱藏。

**信箱登入失敗：** 確認填的是授權碼／App 專用密碼、IMAP 已啟用、帳號沒有被管理員限制。

**日程連線成功但沒有安排：** 手動同步所選月份，確認平臺授權的日曆包含該日程；出現錯誤時保留錯誤文字即可，不要提供密碼。

**驗證碼沒有馬上出現：** 確認郵件是否已到達收件匣，而非垃圾郵件匣；檢查島仔是否執行、連線是否正常。

**圖示或佈局異常：** 回報 Windows 版本、螢幕縮放比例、顯示器數量和截圖。截圖先遮蔽帳號、驗證碼及私人日程。
