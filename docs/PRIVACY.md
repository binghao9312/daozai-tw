# 隱私與安全

## 本機資料

島仔預設在 `%APPDATA%\Daozai` 儲存使用者設定、待辦、本機日程及提醒設定、飲水記錄、置物檔案路徑、連線中繼資料以及忽略的郵件日程識別碼。環境變數 `DAOZAI_DATA_DIR` 可指定另一目錄。置物架儲存原檔案路徑，不複製檔案內容。本機日程不上傳到工作日曆。

信箱和日曆密碼透過 Windows 憑據管理器儲存；獨立 Gemini 工作階段與豆包網頁工作階段使用目前 Windows 使用者的 DPAPI 加密。連線中繼資料中可能包含信箱地址、帳號名稱和本機登入檔案路徑，因此整個資料目錄都不適合公開上傳。

程式讀取收件匣內的郵件以展示內文、提取驗證碼與日曆邀請。目前郵件記錄儲存在記憶體中；不要將執行中的記憶體傾印公開分享。

## 網路存取

音樂相容功能會唯讀存取汽水音樂、酷狗音樂的本機歌詞快取，以及網易雲音樂的本機播放日誌和播放佇列；酷狗設定僅用於提取歌詞目錄。只保留歌詞、歌曲 ID、歌名、歌手、專輯、公開封面網址、播放狀態和時間軸，本地佇列缺少網易雲曲目資訊時按歌曲 ID 向網易雲查詢；系統和本機均未提供封面時，會用歌名和歌手向網易雲搜尋並下載符合的專輯縮圖。日誌內容、音訊簽名連結等內容不會儲存或上傳。網易雲原生播放事件不依賴 SMTC 或固定記憶體位址；必要時仍可對已比對的網易雲、酷狗版本只讀取得播放進度。不會修改播放器、讀取音訊或提取登入資訊。啟動或執行異常的診斷日誌儲存在資料目錄的 `diagnostics/last-error.log`，不會自動上傳。

啟用對應功能後，程式會聯絡信箱 IMAP 服務、工作日曆 CalDAV / Exchange ActiveSync 服務、AI 服務額度介面以及歌詞服務。連線方式和伺服器見原始碼中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及對應 provider 模組。

音樂識別不完整時，本地診斷日誌可能包含播放器名稱、歌名、歌手和歌曲 ID。影片或類型未識別的媒體只記錄來源與缺少的資訊。匯出的診斷包由使用者自行選擇是否分享。

Windows 下的工作日曆連線使用系統 TLS 和憑證信任庫，保留憑證有效期及伺服器名稱驗證。自簽憑證或私有 CA 需要先由使用者或管理員加入 Windows 信任庫。日曆診斷日誌只記錄服務類型、同步範圍、錯誤分類和數量統計，不記錄伺服器位址、憑據或日程內容。

開啟天氣模組後，程式會存取 Open-Meteo 取得天氣；手動指定城市時向其地理編碼服務傳送城市名，自動定位時優先透過 `https://ipwho.is/` 取得網路出口的大致城市與座標，失敗時嘗試 `https://free.freeipapi.com/api/v1/json`，再用座標查詢天氣。請求優先直接連線，必要時可退回到使用者已設定的系統或環境變數代理，兩個定位服務的直接連線嘗試先於代理嘗試。自動重新整理間隔為 15 分鐘，關閉天氣模組後不再發起新一輪查詢，進行中的結果不更新介面或快取。天氣查詢不讀取帳號、信箱或日程資料。各城市最近一次天氣快照儲存在資料目錄的 `weather-cities.json`，供斷網時檢視；系統 TUN/VPN、代理和共享網路出口仍可能影響定位位置。

切換為和風天氣後，城市搜尋、實況和七日預報只存取使用者提供的官方 `qweatherapi.com` 專屬網域，使用 HTTPS 和 `X-QW-Api-Key` 請求標頭，不跟隨重新導向。Key 僅儲存在 Windows 憑據管理器，不寫入一般設定、日誌、診斷包或天氣快取。和風城市需重新手動選擇，不重複使用 Open-Meteo 的座標或自動定位；預設來源及其已儲存城市保持不變。

和風實況約每 60 分鐘、預報約每 6 小時重新整理，僅排程目前城市；天氣快取與請求計數分別儲存在 `qweather-cache.json` 和 `qweather-usage.json`，來源及使用者選擇儲存在 `weather-provider.json`。本機每自然月最多 5,000 次對外嘗試，搜尋、連線測試、手動重新整理及失敗嘗試統一先記帳再傳送；計數無法儲存時停止請求。關閉天氣頁面模組後停止和風新請求並捨棄進行中的結果，狀態元件開關只控制常駐顯示。和風帳號的免費額度由同一帳號的其他裝置和專案共享，島仔無法限制其他應用的用量。

天氣連線診斷儲存在 `diagnostics/weather-network.log`，只記錄請求階段、服務網域、直接連線或代理、耗時和錯誤類別，不記錄 IP、經緯度、城市查詢參數、代理位址或憑據。每份日誌最多 256KB，輪轉保留上一份，不會自動上傳。

島仔啟動後會自動存取 GitHub 的公開發布介面，成功檢查後間隔 24 小時，失敗後間隔 1 小時重試。也可以手動點選「檢查更新」。請求標頭包含島仔版本號，不傳送本地設定、信箱或日程資料。下次檢查時間和已提醒的版本號儲存在本機。選擇「下載並安裝」會從 GitHub 下載公開安裝包至 `%LOCALAPPDATA%\Daozai\Updates`，核對大小及 SHA-256 後替換程式並重啟；「瀏覽器下載」透過預設瀏覽器開啟發布頁。

程式不使用統一的島仔雲端帳號，也沒有專案自建的郵件或日程上傳後端。第三方服務自身的資料處理政策仍然適用。

## 登入憑據

中轉站的自訂查詢指令碼與其中的憑據由目前 Windows 使用者的 DPAPI 加密儲存；執行指令碼時僅存取所設定網站的 HTTPS 介面，不向其他網站傳送憑據。一般 API Key 與 New API 使用者 Token 仍儲存在 Windows 憑據管理器中。

本機 AI 用戶端的登入檔案唯讀使用，不修改原用戶端設定或替它重新整理登入。獨立連線的憑據由島仔自己的安全儲存管理。不要把 Cookie、授權碼、登入 JSON、憑據檔案、真實郵件或私人日程提交到 GitHub。
